# 工业设备调试上位机

基于 **C# WinForms / .NET 10** 的 Windows 上位机，使用真实 COM 串口和 RS-485 MODBUS RTU 与 `D:\github\temp2\温湿度气压MS8607` 硬件固件通信。寄存器对照表位于项目根目录 `寄存器说明.txt`；与硬件源码不一致的项目按硬件实际处理方式实现，并在下文列明。

## 通信参数

- APP 默认地址：`01`
- APP 默认波特率：`9600`
- 串口格式：`8N1`（8 数据位、无校验、1 停止位）
- APP 支持波特率：`9600`、`19200`、`115200`
- BOOT 固定波特率：`9600`，8N1

打开软件后选择串口并连接设备。连接后读取寄存器 20–24 取得 Flash 配置；扫描会自动尝试 9600、19200、115200，地址仍需填写设备当前地址。硬件源码的 CRC helper 返回值和字节拼接写法看似反序，但两者组合后线上仍是标准 RTU 的低字节优先；上位机按此顺序发请求，并兼容校验两种响应字节序。

## 寄存器

| 功能 | 地址 | 含义 | 上位机处理 |
|---|---:|---|---|
| 03 只读 | 0 | 温度 | 有符号 16 位，原始值 ÷ 10，显示 ℃ |
| 03 只读 | 1 | 湿度 | 原始值 ÷ 10，显示 %RH |
| 03 只读 | 2 | 气压 | 硬件 APP 的 MS8607 压力值按 hPa × 10 写入，原始值 ÷ 10，显示 hPa |
| 03 只读 | 15 | APP 程序版本 | 读取硬件 `Reg[15]` 的十进制 16 位值，例如 `60062` |
| 06 写入 | 17 | 进入升级模式 | 写入 `0x1234` |
| 03/06 | 20 | 温度校准 | 寄存器值为有符号整数 -999–999；界面输入/显示 -99.9–99.9，写入时按 10 倍换算 |
| 03/06 | 21 | 湿度校准 | 寄存器值为有符号整数 -999–999；界面输入/显示 -99.9–99.9，写入时按 10 倍换算 |
| 03/06 | 22 | 气压校准 | 寄存器值为有符号整数 -999–999；界面输入/显示 -99.9–99.9，写入时按 10 倍换算 |
| 03/06 | 23 | 设备地址 | 硬件实际接受 1–247 |
| 03/06 | 24 | 波特率编码 | `0=9600`、`1=19200`、`2=115200` |

点表与硬件源码有两处需要注意：点表把地址范围写为 `0–99`，硬件 0x06 处理程序实际只保存 `1–247`；点表给出 Reg[2] 范围 `450–1200`，硬件 APP 则将 MS8607 的 hPa 值乘 10 后写入该寄存器（典型气压原始值约为 10000）。当前上位机按硬件源码实现地址和压力换算。如果设备实际烧录的固件版本与此源码不同，应重新确认这两项定义。

寄存器 20–24 保存在内部 Flash，硬件说明擦写寿命约 1 万次；避免重复高频写入。未定义的寄存器 3–14 不会被访问。读取或写入时会校验从站地址、功能码、长度和 CRC，并记录设备异常响应及串口错误。

## 固件升级

1. 设备处于 APP 模式且已连接时，先选择 BOOT 支持的 `.bin` 固件。文件需为 1–21,500 字节；BOOT 使用一个 21 KiB 活动 APP 区和一个 21 KiB 回滚备份区，CRC 保存在双份升级元数据中。
2. 点击“切换 BOOT”。上位机写入寄存器 17 的 `0x1234`，然后将串口切换到 BOOT 固定的 9600 bps。
3. 尽快点击“开始升级”。BOOT 等待 YMODEM 文件的超时为 100 秒；超时后如果备份有效会自动恢复已确认版本。
4. 传输完成后，上位机等待 BOOT 校验及复位，自动扫描并连接 APP，读取寄存器 20–24 验证 APP 已恢复。

传输使用 YMODEM CRC16，文件信息块和结束空包为 128 字节 SOH，固件数据使用 1024 字节 STX 包；这与 BOOT 接收器支持的 SOH/STX 格式兼容。BOOT 会校验文件长度、包序号、每包 CRC16、整镜像 CRC32 和启动向量，只有完整校验通过才进入 APP 试运行。试运行 APP 启动后由 APP 提交为正常版本；如果试运行期间复位达到 3 次，BOOT 自动从备份区恢复上一版。掉电或断线发生在备份、接收、元数据提交任一阶段时，双份元数据和备份区用于恢复，BOOT 不会跳转到无效 APP。

## 构建

在 Windows 上安装 .NET 10 SDK 后，进入上位机项目所在目录（当前文件夹仍为 `test`），运行：

```powershell
dotnet restore SHT85.csproj
dotnet build SHT85.csproj
dotnet run --project SHT85.csproj
```

项目使用 `System.IO.Ports` NuGet 包访问 Windows 串口。当前验证为本机编译；尚未连接实际设备验证串口、电气层及固件升级。
